# noaction_analysis — 무행동(No-action) 분석 깊이 가이드

> competitor-radar의 척추. 1인 기업가의 진짜 적.

## 3층 진단
| 층 | 질문 | 예(노트프렌즈) |
|---|---|---|
| 1층 현황 | 무행동 비율 % | 회의 후 흘려보냄 78% |
| 2층 이유 | 왜 안 하는가 | "정리 시간이 따로 없어서" |
| 3층 트리거 | 무엇이 깨뜨리나 | "회의 끝 자동 1쪽이 떨어지면" |

## 핀포인트 메시지 공식
"[이유]를 [트리거]로 깨드립니다" → "정리 시간 0으로, 회의 끝 30초에 1쪽 자동 발행."

## 인터뷰 질문 5
①지금 이 문제를 어떻게 처리하나 ②안 하면 무슨 일 ③왜 미루나 ④돈 내고서라도 풀 만큼 아픈가 ⑤어떤 계기면 시작하겠나.

## 데이터 소스
시장 침투율·미도입률 통계가 곧 무행동 비율. KOSIS·산업연구원·업계 리포트 인용.

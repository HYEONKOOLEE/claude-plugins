# competitor-radar — 3유형(MECE) 경쟁 분석 + 무행동 진단 (v2)

> **한 줄 정의**: 매주 4시간 걸리던 경쟁 분석을 *직접·대체·무행동 3유형 MECE* 자동 분석으로 **30분 1쪽 보고서**로 정리해주는 스킬

> **차별 포인트**: 1인 기업가의 *진짜 적*은 경쟁사가 아니라 **고객이 아무것도 안 하는 무행동(No-action)**. 이걸 1순위로 분석 골격에 박은 게 본 스킬의 핵심.

> **v2 핵심 변경 (2026-05-16)**:
> - 모든 경쟁사·시장 데이터 인용 시 **발화 시점 웹 리서치 의무화** (학습 데이터 한계 보완)
> - 경쟁사 매출·점유율·가격은 *반드시 1차 출처 URL 동반* (단일 출처 의존 금지)
> - 학습 데이터 단독 답변 시 *반드시 명시*: "(주의: 학습 데이터 기준이며 변경 가능)"

## 3. 처리 흐름 (Process)

### 0-1. ⭐ 발화 시점 웹 리서치 의무 (3유형 분석 진입 시 필수)

**학습 데이터의 한계 보완을 위해, 본 스킬은 다음을 반드시 웹서치로 선행한다:**

| 분석 유형 | 필수 웹서치 키워드 |
|---|---|
| ① 직접 경쟁 | "[도메인] 경쟁사 [현재 연도]", "[경쟁사명] 매출 OR ARR OR MAU", "[경쟁사명] 가격 정책" |
| ② 대체재 | "[고객 문제] 해결 방법 [현재 연도]", "[도메인] 대체 솔루션 OR 무료 툴" |
| ③ 무행동 | "[고객 문제] 무행동 OR 미해결", "[도메인] 시장 침투율 OR penetration rate [현재 연도]" |
| 공통 — 시장 규모 | "[도메인] 한국 시장 규모 [현재 연도] KOSIS OR 산업연구원", "global [domain] market size [year]" |

**출력 시 인용 규칙**:
- 모든 경쟁사 매출·점유율·가격·기능 인용은 **출처 URL 동반 필수** (회사 IR, 미디어, 공식 가격표 등)
- 시장 규모(TAM·SAM)는 **한국 1차 출처 + 글로벌 출처** 최소 2건 교차
- 단일 출처(예: Statista 1건) 의존 **금지**
- 학습 데이터로만 답변 시 *반드시 명시*: "(주의: 학습 데이터 기준이며 [날짜] 이후 변경 가능)"

자세한 한국 산업 데이터 출처 풀은 `references/industry_data_sources.md`(§ 과업 0) 참조.

### 1. 스코프 정의 (2분)
- 사업 아이템 한 줄 정의를 그대로 가져옴
- 분석 지리적 범위 (한국 / 글로벌 / 특정 도메인)
- 분석 깊이 (요약 1쪽 / 상세 3쪽)

### 2. 3유형 분류 (MECE 검증)

| 유형 | 정의 | 1인 기업가에 대한 위험 |
|---|---|---|
| **직접 경쟁(Direct)** | 같은 카테고리·같은 솔루션 | 3순위 — 가격·기능 싸움 |
| **대체재(Substitute)** | 다른 방식으로 같은 문제 해결 | 2순위 — 가성비 싸움 |
| **무행동(No-action)** ★ | 고객이 그냥 아무것도 안 하는 선택 | **1순위 — 진짜 적** |

→ MECE(Mutually Exclusive·Collectively Exhaustive) 자동 검증: 누락·중복 0 보장

### 3. 9개 섹션 자동 작성 (3유형 × 3깊이)

| 깊이 | 직접 경쟁 | 대체재 | 무행동 |
|---|---|---|---|
| **현황** | 상위 3사 매출·점유율 | 대체 방식 가격·도입 비율 | 무행동 비율 % + 이유 |
| **전망** | 3년 내 시장 점유 변화 | 대체재가 진화하는 방향 | 무행동이 깨질 트리거 |
| **우리 대응** | 차별점 1줄 | 가성비 메시지 | 무행동 핀포인트 메시지 |

→ 각 섹션 *출처 1건 이상* 자동 인용 (research_notes + 통계청 등)

### 4. 1순위 Pain 도출
- 9개 섹션을 종합해 **고객의 1순위 Pain** 1개 추출
- 그 Pain이 *무행동* 유형에 매칭되는 경우 우선순위 ★

### 5. 핸드오프 메모 자동 생성
- 1순위 Pain → MRD-writer로 패스
- 무행동 분석 → brand-strategy-designer의 Hook 설계로 패스

## 4. 사용 프레임워크

| 단계 | 프레임워크 |
|---|---|
| 분류 | MECE (Mutually Exclusive·Collectively Exhaustive) |
| 깊이 | 3시점 분석 (현황·전망·대응) |
| 우선순위 | 1인 기업가 위험도 3순위 (무행동 > 대체재 > 직접) |
| 인용 | APA-lite (출처명 · 연도 · 핵심 숫자) |

**받을 사람**: `MRD-writer` (2일차 블록 C) + `brand-strategy-designer` (블록 D)

- 무행동 비율 % + 이유 (brand-strategy의 Hook 설계 입력)

1. 1순위 Pain: (무행동 분석 결과 1줄)
2. 무행동 비율: __% — 이유: (...)
3. 진입 장벽 가설: (빅테크 대비 우리 방어막)

- MRD-writer: 1순위 Pain을 *시장 요구사항* 1번 항목으로 박기

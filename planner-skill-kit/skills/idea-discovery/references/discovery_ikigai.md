# discovery_ikigai — 이키가이 4요소 (내부 강점 출발)

> idea-discovery §1 경로 ④. context.md의 IKIGAI 4축을 시작점으로.

## 4요소 교집합
- LOVE 좋아하는 것 / GOOD AT 잘하는 것 / NEEDS 세상이 필요로 함 / PAID FOR 돈 받을 수 있는 것
- 4개 모두 겹치는 지점 = 이키가이(지속가능한 사업 코어)

## 입력 양식
| 축 | 내 답 | 근거 |
|---|---|---|
| LOVE | | |
| GOOD AT | | (경력·자격·실적 숫자) |
| NEEDS | | (시장 통계·미충족 수요) |
| PAID FOR | | (실제 결제 의지·단가) |

## 진단
- LOVE+GOOD만 → 취미(돈 안 됨) / NEEDS+PAID만 → 번아웃 위험. **4축 교집합**에서 후보 도출.

## 예 (대표 context.md 기반)
LOVE: AI 활용·중소기업 AI 도입 / GOOD AT: 30년 기획·7년 사업계획 평가·AI 강의 280회 / NEEDS: 중소 AI 격차(미도입 94.7%) / PAID FOR: 진단·컨설팅·정부지원 연계 → 코어 = **AI 도입 진단·실행 컨설팅**.

# discovery_policy — 정책 기반 아이디어 발굴 (풀 가이드)

> idea-discovery §1 경로 ① 정책 기반. **발화 시점 웹 리서치 필수.**

## 과업 0 — 발화 시점 웹서치 (학습 데이터 한계 보완)
아래 키워드를 *현재 연도*로 치환해 검색하고, 인용 시 **출처 URL + 발행일** 동반:
- "[현재 연도] 중기부 창업지원 통합공고"
- "이재명정부 국정과제 [도메인]"
- "[현재 연도] TIPS OR 모태펀드 OR 초격차 스타트업"
- "[현재 연도] [도메인] 바우처 지원사업"

규칙: 단일 출처(예: 국정과제 1건) 인용 금지 → **최소 3개 출처 교차**. 학습 데이터만 쓸 땐 "(주의: 학습 데이터 기준, [날짜] 이후 변경 가능)" 명시.

## 정책 정합성 가중치 (후보 평가)
| 가중 요소 | 배점 | 설명 |
|---|---|---|
| 국정과제 직접 정합 | 30 | 123대 국정과제 키워드 직접 매칭 |
| 예산 흐름 정합 | 25 | 올해 통합공고에 해당 분야 예산 존재 |
| 자격 적합 | 20 | 업력·매출·대표 요건 충족 |
| 바우처/연계 가능 | 15 | 바우처·R&D·수출 등 연계 |
| 시의성 | 10 | 올해 신규·확대 사업 |

## 산출 형태
후보마다: 아이템 한 줄 / 매칭 국정과제 / 연계 가능 사업명 + 예산 / 출처 URL 2건.

# discovery_scamper — SCAMPER 7원칙 (기존 아이템 강화)

> idea-discovery §1 경로 ③. 이미 아이템이 있을 때 변형·확장.

| 원칙 | 질문 | 1인 창업 적용 예 |
|---|---|---|
| S Substitute | 무엇을 대체? | 사람 응대 → AI 챗 응대 |
| C Combine | 무엇과 결합? | 진단 + 실행 패키지 묶음 |
| A Adapt | 어디서 차용? | 헬스 구독모델을 컨설팅에 |
| M Modify/Magnify | 키우거나 줄이면? | 풀컨설팅 → 90일 동행 축소 |
| P Put to other use | 다른 용도? | 진단툴을 강의 교보재로 |
| E Eliminate | 무엇을 제거? | 대면 미팅 제거(비동기) |
| R Reverse/Rearrange | 순서 뒤집기? | 선결제 → 성과 후 정산 |

## 산출
기존 아이템 1개 → 7원칙 각 1개 변형 → 매력도·실현성 2축으로 TOP 3 변형 선정.

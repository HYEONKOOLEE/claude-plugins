# 예시 — 노트프렌즈 MRD 완성본

## 1. 시장 정의
TAM 1,500억 / SAM 800억(한국 B2B 영업·컨설팅 회의록) / SOM 24억(3년, 3%).

## 2. 세그먼트
Primary: 10~50인 B2B 영업·컨설팅사 / Secondary: 1~10인 전문직.

## 3. 핵심 문제
1순위: 정리 시간 0이 안 됨(무행동 78%). 2~3순위: 한국어 정확도, 액션 누락.

## 4. 요구사항
기능: 한국어 STT·액션 추출·CRM 연동 / 비기능: 정확도 95%+·보안 / 제약: 1인 운영.

## 5. 성공 지표
유료 전환 30% · MAU · churn<5% / NPS 50+ · 인터뷰 만족 80%.

## 6. MoSCoW
Must: STT95·액션·CRM / Should: 화면분석·영어 / Could: 감정 / Won't: 50인+·통역·화상도구.

## 핸드오프 → brand-strategy + 6주차 PRD
Must 3개 + Primary 가설 + KPI 3개.

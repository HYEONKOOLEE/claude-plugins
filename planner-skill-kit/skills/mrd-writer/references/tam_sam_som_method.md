# tam_sam_som_method — TAM/SAM/SOM 산정법 + 한국 데이터 출처

> mrd-writer §섹션1. **발화 시점 웹서치 필수.**

## 3층 정의
- TAM 전체 시장(글로벌) / SAM 한국·도메인 한정 / SOM 1~3년 현실 점유

## 산정 3법
| 방법 | 공식 | 신뢰도 |
|---|---|---|
| Top-down | TAM × 한국 비중 × 도메인 비중 | ★★ |
| Bottom-up ★ | 단가 × 잠재 고객 수 (권장) | ★★★ |
| Value Theory | 고객 연 Pain 비용 × 잠재 고객 | ★★ |

## 과업 0 웹서치
"global [domain] market size [연도]" / "한국 [도메인] 시장 규모 [연도] KOSIS OR 산업연구원" / "[고객층] 기업·인구 수 통계청"
→ 글로벌 1 + 한국 1 최소 2건 교차, 출처 URL+발행일.

## 흔한 실수
1. TAM만 적음 → SAM+SOM 함께 2. SAM=TAM → 한국·도메인 좁히기 3. SOM=SAM의 50%+ → 1~10% 권장 4. 근거 없음 → 출처+연도.

## 예 (노트프렌즈 Bottom-up)
월 25만원 × 12 × 5만 곳 = TAM 1,500억 / ×53%(B2B SaaS 침투) = SAM 800억 / ×3% = SOM 24억(현실 목표).

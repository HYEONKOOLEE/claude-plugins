# moscow_priority — MoSCoW 우선순위 분류

> mrd-writer §섹션6. 1인 기업가 스코프 보호의 핵심.

| 분류 | 정의 | 운영 의미 |
|---|---|---|
| Must | 없으면 출시 불가 | MVP 범위 = Must만 |
| Should | 있어야 경쟁력 | v1.1~v1.2 |
| Could | 있으면 좋음 | v2 이후 |
| ★Won't | 이번 사이클 안 함 | 명시적 배제(스코프 보호) |

## Won't가 핵심인 이유
안 적으면 6개월 후 "이것도 해야 하나?"로 흔들림. 1인 기업가에게 집중 = 생명.

## 예 (노트프렌즈)
Must: 한국어 STT 95%+·액션 자동추출·CRM 연동 / Should: 화면공유 분석·영어 / Could: 음성 톤·감정 / **Won't: 50인+ 회의·실시간 통역·화상회의 도구 자체.**

→ 6주차 PRD는 Must만 가져감.

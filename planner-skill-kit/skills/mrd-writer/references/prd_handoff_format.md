# prd_handoff_format — 6주차 PRD 입력 양식

> mrd-writer 핸드오프(6주차 MVP 기획).

## 전달 항목
1. Must-have 요구사항 3개 (= PRD 기능 요구사항 시드)
2. Won't 목록 (= PRD 스코프 보호 기준)
3. Primary 세그먼트 가설 1줄
4. 정량 KPI 3개 + 1년 목표 (= 출시 성공 기준)
5. TAM/SAM/SOM (= 시장 정의 근거)

## 형식
```
## PRD 입력 (MRD → PRD)
- Must: A / B / C
- Won't: X / Y / Z
- Primary: ...
- KPI: ... (1년 목표 ...)
```

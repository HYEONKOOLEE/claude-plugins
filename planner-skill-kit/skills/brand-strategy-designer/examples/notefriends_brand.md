# 예시 — 노트프렌즈 (B2B SaaS) 브랜드 전략 완성본

## Hook
"회의 1시간에 정리 3시간이 들었습니다. 그게 안 들게 만드는 게 우리 일입니다."

## 미션·비전·핵심가치
미션 "1인 기업가의 회의 시간을 영업 시간으로 회수" / 비전 "한국 B2B 영업 회의록 SaaS 1위" / 가치: 정직·도메인 깊이·1인 운영 / 성격: 전문적·조용함·따뜻함.

## 네이밍·슬로건
노트프렌즈 / "회의 끝, 정리는 끝."

## Value Ladder
무료 1회 요약 → 진입 1만원대 → Core 월 5만 → 팀 구독 월 25만 → 프리미엄 도입 컨설팅 100만.

## 30일 플랜
1주 브랜드 확정 / 2주 Lead Magnet / 3주 콘텐츠 / 4주 첫 5명.

## 핸드오프 → proposal-writer
Hook + 미션·비전 + 30일 플랜.

# brand-strategy-designer — 브랜드 전략 5단계 통합 설계 (v2)

> **한 줄 정의**: MRD가 정제한 *시장 요구사항*에 대한 우리 회사의 **영혼·스토리·수익 골격**을 5단계로 자동 설계해, 3주차 마케팅 실행 자산의 *근거 문서*가 되는 스킬

> **차별 라인**: 1주차 = *브랜드의 영혼·스토리·수익 골격* / 3주차 권정선 = *그 위에 시각·언어·콘텐츠 실행 자산*. 두 영역이 *상하관계*로 깨끗하게 분리.

> **v2 핵심 변경 (2026-05-16)**:
> - 카테고리 트렌드·소비자 행동·가격 가설 산정 시 **발화 시점 웹 리서치 의무화**
> - 벤치마크 브랜드·Value Ladder 가격은 **출처 URL 동반 필수** (단일 사례 모방 금지)
> - 학습 데이터 단독 답변 시 *반드시 명시*: "(주의: 학습 데이터 기준이며 변경 가능)"

## 1. 언제 호출되나

### Description 매칭 키워드
- *브랜드 전략*, *브랜드 설계*, *브랜드 스토리*
- *미션 비전*, *핵심가치*, *브랜드 성격*
- *네이밍*, *슬로건*, *Hook*, *Epiphany Bridge*, *StoryBrand*
- *Value Ladder*, *수익화 모델*, *30일 실행 플랜*

### 사용 시나리오 3가지
1. **MRD 완성 직후** — 시장 요구사항에 대한 우리 회사의 *응답*을 설계
2. **정부지원 신청서 *추진 의지·차별성* 섹션 작성 시** — Hook과 미션·비전이 평가자 설득력 증대
3. **3주차 권정선 강사 입력 자료 준비** — 페르소나·카피·디자인의 *근거 문서* 역할

## 3. 처리 흐름 (Process) — 5단계 (3주차 영역 제외)

### 0-1. ⭐ 발화 시점 웹 리서치 의무 (단계 ①②④⑤⑦ 진입 시 필수)

**학습 데이터의 한계 보완을 위해, 본 스킬은 다음을 반드시 웹서치로 선행한다:**

| 적용 단계 | 필수 웹서치 키워드 |
|---|---|
| ① Dream Customer | "[타깃 세그먼트] 라이프스타일 [현재 연도]", "[고객층] SNS·미디어 소비 행태 [현재 연도]" |
| ② Hook & Bridge | "[현재 연도] 한국 소비자 페인포인트 [도메인]", "[도메인] 고객 인터뷰 OR 후기 트렌드" |
| ④ 네이밍·StoryBrand | "[도메인] 브랜드 네이밍 트렌드 [현재 연도]", "[카테고리] 도메인 상표 검색 KIPRIS", "성공 브랜드 사례 [현재 연도]" |
| ⑤ Value Ladder 가격 | "[도메인] SaaS OR 제품 가격대 [현재 연도]", "[경쟁사] 가격 정책 OR 구독료" |
| ⑦ 30일 실행 플랜 | "[현재 연도] 한국 소비 트렌드", "[도메인] 마케팅 채널 효과 [현재 연도]" |

**출력 시 인용 규칙**:
- 카테고리 트렌드·소비자 행동 인용은 **출처 URL 동반 필수**
- 벤치마크 브랜드 3개·안 닮고 싶은 브랜드 3개는 **공식 사이트·미디어 URL 동반**
- Value Ladder 가격 가설은 **경쟁사·대체재 실제 가격 최소 3건 교차** 후 설정
- 네이밍 후보는 *KIPRIS·도메인 등록* 1차 확인 가능성 명시
- 학습 데이터로만 답변 시 *반드시 명시*: "(주의: 학습 데이터 기준이며 [날짜] 이후 변경 가능)"

자세한 트렌드·가격 가설 출처는 `references/value_ladder_pricing.md`(§ 과업 0)·`references/hook_epiphany_bridge.md`(§ 과업 0) 참조.

### 단계 ① Dream Customer 가설 (Persona Seed)
- MRD의 Primary 세그먼트를 *Dream Customer 1명*으로 의인화
- 라이프스타일·언어·자주 보는 채널 *가설* 수준 (페르소나 카드 정식 완성은 3주차 권정선)
- Dream100 채널 가설: *이 사람이 자주 보는 곳·자주 듣는 인플루언서* 5개씩

### 단계 ② Hook & Epiphany Bridge ★ (1주차 고유)
**Hook (1줄)**: 1순위 Pain을 거꾸로 뒤집은 *공감 한 줄*
- 예: *"좋다는 화장품보다, 내 피부가 편안한 화장품이 필요했습니다."*

**Epiphany Bridge (3~5문장 스토리)**: 창업자의 *깨달음의 순간*
- 시작: 창업자가 겪었던 *옛 고통*
- 전환: *깨달음의 순간* (왜 기존 방법이 안 통했나)
- 결말: *그 깨달음으로 만든 솔루션이 우리 사업*

→ Hook + Bridge는 *모든 마케팅 메시지·신청서·IR의 첫 문장*이 됨.

### 단계 ③ 브랜드 퍼스낼리티 ★ (1주차 고유)
- **미션**: 우리가 *왜 존재하는가* 1문장
- **비전**: 5년 후 *어떤 자리에 있을 것인가* 1문장
- **핵심가치 3개**: *모든 결정의 기준* (각 한 단어 + 설명 1줄)
- **브랜드 성격**: 형용사 3개로 정의 (예: 조용함·전문적·따뜻함)

### 단계 ④ 네이밍·슬로건·스토리텔링 (시각 디자인은 3주차로 양도)
**네이밍**: 3~5개 후보 + 각 의미·발음·도메인 확보 가능성
**슬로건**: 3개 후보 (한국어 + 영어 짧은 1줄)
**StoryBrand 7요소**:
1. 캐릭터 (고객 = 영웅)
2. 문제 (외부·내부·철학적 3층)
3. 가이드 (우리 회사)
4. 계획 (3단계로 명확히)
5. 행동 요청 (직접 CTA + 전환 CTA)
6. 성공 (얻을 것)
7. 실패 회피 (안 하면 잃을 것)

※ 컬러 팔레트·폰트·패키지·로고 등 *시각 디자인 시스템*은 **3주차 권정선 강사 brand_designer 영역**으로 양도.

### 단계 ⑤ Value Ladder 5단계 가설 (실행 카피는 3주차로 양도)

| 단계 | 상품 | 가격 가설 | 1인 운영 의미 |
|---|---|---|---|
| 무료 | Lead Magnet | 0원 | 진단 테스트·체크리스트 |
| 저가 (Tripwire) | 진입 상품 | ~1만원대 | 미니 체험·샘플 |
| 중가 (Core) | 메인 상품 | 5~10만원 | 본 제품·서비스 |
| 고가 (Profit Maximizer) | 정기 구독 | 월 5~10만원 | 반복 매출 |
| 프리미엄 | 1:1 컨설팅 | 30~300만원 | 마진 극대화 |

→ Value Ladder *가설* 5단계까지. *랜딩 메시지·세일즈 퍼널 실행* 은 3주차 권정선 강사 wpgopc·landing_copy로 위임.

### 단계 ⑦ 수익화 모델 + 30일 실행 플랜 ★ (1주차 고유)
**수익화 모델 5종 후보**:
- 구독 / 단건 판매 / 프리미엄 컨설팅 / B2B 라이선스 / 부가 상품

**30일 실행 플랜 (1주 단위 4분기)**:
| 주차 | 실행 |
|---|---|
| 1주 | 브랜드 아이덴티티 1차 확정 (네이밍·슬로건) |
| 2주 | 무료·저가 상품 정의 + Lead Magnet 1개 작성 |
| 3주 | 인스타·블로그 콘텐츠 10편 1차 (3주차 권정선과 연계) |
| 4주 | 광고 테스트 + 첫 5명 고객 확보 |

※ 단계 ⑥ (랜딩페이지·콘텐츠 마케팅 실행)은 **3주차 권정선 강사 wpgopc·landing·5채널·brand_designer로 완전 양도**.

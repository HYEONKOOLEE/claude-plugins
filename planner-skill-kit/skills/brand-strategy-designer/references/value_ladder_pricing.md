# value_ladder_pricing — Value Ladder 5단계 + 가격 책정

> brand-strategy §단계⑤. (Russell Brunson, 마케팅 설계자/DotCom Secrets)

| 단계 | 상품 | 가격 가설 | 역할 |
|---|---|---|---|
| 무료 | Lead Magnet | 0원 | 진단·체크리스트 |
| 저가(Tripwire) | 진입 | ~1만원대 | 미니 체험 |
| 중가(Core) ★ | 메인 | 5~10만원 | 본 제품 |
| 고가(Profit Max) | 구독 | 월 5~10만원 | 반복 매출 |
| 프리미엄 | 1:1 | 30~300만원 | 마진 극대화 |

## 발화 시점 웹서치
"[도메인] SaaS 가격대 [연도]" / "[경쟁사] 구독료" → **경쟁사·대체재 실제 가격 최소 3건 교차** 후 설정.

## 규칙
무료→프리미엄 자연스러운 상승 동선. 각 단계 전환 트리거 1줄. 랜딩·퍼널 실행은 3주차.

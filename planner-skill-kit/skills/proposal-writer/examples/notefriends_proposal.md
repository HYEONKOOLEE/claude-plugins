# 예시 — 노트프렌즈 예비창업패키지 1쪽 완성본

1. 사업 개요 — "회의 끝 30초에 1쪽 액션이 떨어지는 한국어 회의록 SaaS." (Hook)
2. 추진 배경 — 30대 직장인 회의 후 78% 흘려보냄. 미션: 회의 시간을 영업 시간으로 회수.
3. 시장 분석(PESTEL) — TAM 1,500억/SAM 800억/SOM 24억. AI 정책·AI 기본법. (출처 6건)
4. 차별성(SWOT) — 도메인 27년·한국어 95% vs 빅테크 한국어 진입.
5. 비즈니스 모델(BMC) — 월 구독 5/25/100만, 핵심 파트너 OpenAI·토스.
6. 추진 전략(MECE) — 1년 PoC→2년 도메인 확장→3년 흑자.
7. 핵심 성공 요인(KSF) — STT95(보강)·CRM통합·도메인(USP).
8. 위험·대응 — STT 외주 의존 → 자체 데이터 학습. 1인 한계 → 셀프 온보딩.
9. 성과 — 유료 30건·연 매출 1.5~3억(1년).

★ Before/After: 출처 6건+ / 프레임워크 5개 / 숫자 9개+ → "근거 명확".

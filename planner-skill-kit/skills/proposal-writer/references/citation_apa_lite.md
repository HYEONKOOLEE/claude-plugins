# citation_apa_lite — APA-lite 인용 양식

> competitor-radar·proposal-writer 공용. 평가위원 신뢰도 직결.

## 양식
(출처명, 연도) 핵심숫자 — URL
예: (대한상의 국내기업 AI 활용 실태조사, 2025) 중소기업 94.7% 미도입 — https://...

## 규칙
- 모든 매출·점유율·가격·시장규모는 출처 동반.
- 시장규모는 **한국 1차 출처 + 글로벌 출처** 2건 교차.
- 단일 출처(Statista 1건 등) 의존 금지.
- 학습 데이터만이면 "(주의: 학습 데이터 기준, 변경 가능)" 명시.
- 정부 사업공고는 신청 전 **원문 URL 재확인**.

## 위반 예
"시장이 매우 크다"(숫자·출처 없음) / "글로벌 5조"만 적고 한국 SAM 없음 → 평가위원 "근거 부족".

# framework_swot — SWOT 4분면 + TOWS

> proposal-writer 섹션4 차별성·경쟁력.

|  | 도움(긍정) | 방해(부정) |
|---|---|---|
| 내부 | Strength 강점 | Weakness 약점 |
| 외부 | Opportunity 기회 | Threat 위협 |

## TOWS 전략 도출
- SO 공격: 강점×기회 / WO 보완: 약점 메워 기회 / ST 방어: 강점으로 위협 차단 / WT 회피: 약점+위협 최소화.

## 예(노트프렌즈)
S 도메인 27년·한국어 정확도 / W 1인 운영·인지도 / O 무행동 78%·AI 정책 / T 빅테크 한국어 진입.
→ SO: 도메인 한정으로 빅테크 전에 선점.
